## 1. What the cirrus layer is (facts so far)

- ONE infinitely thin 2D spherical shell, not ray-marched. One texture lookup pair per view ray + 4 extra
  lookups along the sun direction for self-shadow. `CirrusDensity` Volumetrics.cs.hlsl:956-965,
  `IntegrateCirrus` :977-1024, shell intersection UpperCloud.hlsli:173-178.
- Density function (Volumetrics.cs.hlsl:959-964):
  - `weather = TexCirrusWeather(position_m / 16384 / uvSize + 0.5)`  -> x = coverage, y = type. NOT wind-shifted in the
    shader (wind is baked into the map at generation, CirrusGenerate.cs.hlsl:39).
  - `patterns = TexCirrusPatterns((position - cirrusWindOffset)_m * 0.0002331 / uvSize)` -> HARD-CODED scale,
    tile = 1/0.0002331 = 4290 m (x uvSize). This is the analogue of the low layer's `xy * 0.0043545123` (230 m).
  - type picks the channel of cirrus.dds (squared): type 0 -> B, 0.5 -> R, 1 -> G (linear blends between).
  - `profile = pow(profile, 1.9 - 1.8*coverage) * saturate(2*coverage^3)`; density = 2*profile*densityScale;
    view optical depth = density*10 (:1003).
- Pattern texture: `Data/Textures/PhysicalSky/cirrus.dds` (hard-coded path Ndf.cpp:785), 1024x1024 BC7, ONE mip,
  sampled at mip 0 always. Deployed copy (mods/Bottled Shaders - foxnne/textures/PhysicalSky/cirrus.dds) is
  byte-identical to the repo copy. Channels (extracted to cirrus_R/G/B.png here):
  - B = long fibrous streaks running along texture U (= world X, east-west)  -> true cirrus fibratus
  - R = wispy tufts / patches                                              -> cirrus floccus / spissatus-ish
  - G = dense CELLULAR puff field (cells ~150-170 m, clumps ~1 km)          -> cirrocumulus = THE POPCORN
  - mean of squared value: G ~0.2, R/B ~0.05 -> G is ~5x denser than the other two at the same coverage.
- Weather map: 512x512 RG16F, generated by CirrusGenerate.cs.hlsl from the four shared weather-noise slots
  (the same `cloudMap.procedural.noise[0..3]` the low layer uses). Covers 16384 m x uvSize, tiles.
  - coverage default: slot 1, frequency 1, input [-0.7,0.7] -> output [0,0.6]  (Ndf.h:271)
  - type default:     slot 2, frequency 1, input [-1,1]     -> output [0,1]    (Ndf.h:271, CirrusNoiseLayer{} Ndf.h:260-266)
  - slot 2 default = Perlin, base frequency 32, 4 octaves (Ndf.h:120) -> type varies on a 512 m base cell
    (16384/32) with octaves down to 64 m. Every place type > 0.5 the dense G channel is blended in. Result: a
    uniform field of ~0.25-0.5 km blobs of cellular texture = evenly spaced puffs. This is the main cause.
  - slot 1 default = Perlin, freq 4, 6 octaves, repetitions 2 (Ndf.h:119) -> coverage base cell 2048 m and the
    coverage map REPEATS every 8192 m (x uvSize) because of repetitions 2.
- Middle layer (`cloudLayer.middle`, MidCloud.hlsli) is a separate ray-marched As/Ac deck at 3500 m.
  Default `enabled = false` (Ndf.h:359); SettingsUser.json does not set it; the sweep did not set it. So the
  popcorn is NOT the middle layer. It is the cirrus shell showing the G (cirrocumulus) channel.
- User's SettingsUser.json only has `cloudLayer.cirrus.densityScale = 0.3`; everything else cirrus = defaults.

## 2. Evidence from frames and simulation

- Sweep frames (results/sky_sweep/clearcover-ilinalta): the dense carpet of small puffs is in 00_ref, 04, 05, 06
  (low-layer `cloudMap.procedural.parameters.primary.range` input min = -0.4) and is gone in 01-03 where ONLY that
  low-layer input min was raised, cirrus still 1.0. So most of that carpet is the LOW layer. The cirrus-only
  contribution is the difference 02 (1.0) / 07 (0.4) / 08 (off): soft isolated clumps 40-100 px wide
  (about 1-2.5 deg) scattered evenly over the sky. Precise repeat could not be counted in the frames (low
  cumulus overlap, view only spans 3-17 deg elevation).
- sim.py / sim2.py re-implement the noise + CirrusGenerate + CirrusDensity (no lighting). Default settings
  reproduce the look: evenly spaced blobs on a visible lattice (sim_A_default_d1.0.jpg, sheet_settings.jpg row 1).
  Cause = coverage gate `saturate(2*cov^3)` with coverage output max 0.6 passes only the Perlin peaks of slot 1
  (2 km cells) -> isolated 0.5-1 km blobs; slot 1 has repetitions 2 so the blob layout repeats every 8192 m;
  type noise (512 m) switches the dense G cellular channel on inside the blobs.
- Geometry (curvature radius 74.946 km, shell 8 km): distance to shell = 8 km zenith, 10.8 km @45, 14.2 km @30,
  21 km @15, 25 km @10, 35 km at horizon.
  - blob spacing ~2 km:      14 deg zenith, 8 deg @30, ~4.7 deg wide x 2 deg tall @10
  - pattern tile 4290 m:     30 deg zenith, 17 deg @30, ~10 x 4.5 deg @10
  - coverage repeat 8192 m:  54 deg zenith, 33 deg @30, ~19 x 9 deg @10
- Settings-only fix works in sim (sheet_settings.jpg S3/S4/S5): type forced to B (or B..R), coverage remapped to
  a broad range, uvSize 3. Shader prototypes in sheet_shader.jpg (P2 stretch, P3 +warp, P4 +2nd scale +cover mod).
