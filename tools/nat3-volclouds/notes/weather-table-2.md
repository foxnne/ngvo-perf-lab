## Rules

- **Type** (first match): other-realm name prefix -> special; storm rain particles -> storm; day fog far <= 15000 without snow/ash particles -> fog; rain particles -> rain; snow particles -> snow; day fog far <= 100000 or ash particles -> overcast; pleasant flag with at most one cloud layer of alpha, or wind <= 5 -> clear; wind <= 10 -> fair; otherwise partly.
- **Severity**: dark = (0.92 - day sunlight luminance) / 0.72; alpha = (sum of day layer alphas - 3) / 7; all clamped 0..1. fair = alpha; partly = half alpha, half (0.92 - sun) / 0.32; overcast = 0.7 dark + 0.3 cloud-colour darkness; rain = 0.7 dark + 0.3 fog nearness; storm = half dark, half (wind - 100) / 110; snow = half dark, half (wind - 25) / 185, halved when a single cloud layer has alpha; fog = log position of day fog far between 15000 and 4000.
- **Haze**: lo + (hi - lo) x fog nearness, fog nearness = log position of day fog far between 150000 and 5000.
- **Cloud drift**: low = 3 + 0.06 x wind byte m/s (3..16), high = 2 x low, along +X.
- **Height fog**: half-opacity distance at strength 0.3 is computed from the record fog (near, far, power, max) the way the feature does; where it is shorter than the type floor, the strength is lowered so the distance becomes floor x (raw / floor)^0.3. Day values for Sunrise/Day/Sunset, night values for Night, geometric mean for Dawn/Dusk.
- **Aurora** (record has an aurora model; clear/fair/partly only): in Dawn, Dusk and Night inMin + 0.15 and high layer 0.
