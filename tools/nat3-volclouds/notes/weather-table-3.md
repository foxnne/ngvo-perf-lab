## Rules

- **Type and severity**: exactly the pass-2 rules (`build_pass2.classify`), see `weather-table-2.md`.
- **Values**: each type is a list of (severity, values) points in the generator; a weather is interpolated linearly between the two nearest points and clamped at the ends. The points sit on the tested looks where one exists.
- **Haze**: lo + (hi - lo) x fog nearness (log position of day fog far between 150000 and 5000), as a multiple of the saved Continental loading 0.2.
- **Cloud drift**: low = 3.5 + 0.0375 x wind byte m/s, capped at 9; high = 2 x low; along +X.
- **Height fog**: half-opacity distance at the Baseline strength 0.1 is computed from the record fog (near, far, power, max); where it is shorter than the type floor the strength is lowered so the distance becomes max(minimum, floor x (raw / floor)^0.5). Day value for Sunrise/Day/Sunset, night value for Night, geometric mean for Dawn/Dusk.
- **DALC**: the type value in Sunrise/Day/Sunset, half-way to the Baseline 0.5 at Dawn/Dusk, the Baseline value at Night.
- **Rayleigh** (clear/fair/partly): x2 in Dawn, Sunrise, Sunset, Dusk; x1 in Day and Night (both `rayleighScatter` and `rayleighScatterAP1`).
- **High layer**: per type one look (coverage + type pattern as a blend state, altitude) and a density; partly cloudy uses 0.5 at twilight and 0.3 in Day and Night. `uvSize` 3 is global (Baseline).
- **Rain, Day period only**: `modeling.range` z/w widened toward [0.12, 0.9] with severity (more thickness variation at midday).
- **Aurora** (record has an aurora model; clear/fair/partly only): in Dawn, Dusk and Night primary inMin and inMax + 0.15 and high layer 0.
